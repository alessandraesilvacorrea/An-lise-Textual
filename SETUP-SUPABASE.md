# 🚀 Configuração Supabase - Passo a Passo

## 1. Abra o SQL Editor do Supabase

1. Vá para: https://supabase.com/dashboard
2. Escolha seu projeto
3. No menu esquerdo, clique em **SQL Editor**
4. Clique em **+ New query**

## 2. Cole o SQL

Copie o conteúdo do arquivo `setup-database.sql` (localizado na raiz do projeto) e cole na caixa de SQL.

O SQL cria 2 tabelas:
- **users**: Armazena emails dos usuários
- **user_progress**: Armazena tópicos concluídos de cada módulo

## 3. Execute

Clique no botão **▶ Run** (canto superior direito)

Se aparecer "Success", pronto! ✅

## 4. Configuração Concluída

Agora o seu app vai:
- ✅ Salvar dados na nuvem (Supabase)
- ✅ Funcionar em qualquer computador
- ✅ Nunca perder progresso
- ✅ Ser totalmente grátis
